REQUIREMENTS

A. TRÊN MÁY TẤN CÔNG (KALI LINUX - 192.168.188.128)
Công cụ cần cài:
  - nmap                    # Quét mạng, phát hiện cổng RDP
  - crowbar                 # Brute-force RDP (hỗ trợ NLA)
  - hydra (tùy chọn)        # Brute-force đa giao thức
  - xfreerdp                # Client RDP cho Linux

Lệnh cài đặt:
  sudo apt update
  sudo apt install nmap crowbar hydra freerdp2-x11 -y

File chuẩn bị:
  - passwords.txt           # Wordlist chứa 100 mật khẩu phổ biến
  - hacked.txt              # File ẩn để cài vào máy nạn nhân
