Wireshark

Mục tiêu
	1. Cài đặt Wireshark trên Ubuntu
	2. Bắt gói tin khi truy cập Google.com
	3. Bắt gói tin khi ping 8.8.8.8
	4. Bắt gói tin khi SSH localhost
	5. Quan sát và ghi nhận các giao thức hoạt động


1. Cài đặt Wireshark
```bash
sudo apt update
sudo apt install wireshark -y

2. thêm user vào nhóm wireshark
sudo usermod -aG wireshark $USER
restart lại máy

3. Mở wireshark
sudo wireshark
chọn np0s3
truy cập google.com: curl -v http://google.com
ping đến 8.8.8.8: ping -c 4 8.8.8.8 (linux) ping 8.8.8.8 (Window)

4. sử dụng ssh: dùng đề điều khiển ảo  = máy thật
ví dụ: win thật -> ubuntu ảo: dùng máy (window) thật điều khiển máy ảo ubuntu 
lấy ip, username, paswd của máy ảo: 
	+lấy username (1 trong 3 cách): whoami/ echo $USER/ ip
	+lấy ip:(1/2 cách) ip -a / hostname -I
lệnh ssh: ssh username@ip   ->  nhập passwd
sau khi nhập xong từ máy window (cmd/powershell) có thể dùng lệnh linux để điều khiển máy ảo ubuntu
